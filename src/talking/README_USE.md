## 自定义回复插件使用说明

### 基本使用

在控制台 >> 插件管理 >> 插件配置 中添加回复规则。

### 可用变量

| 变量 | 说明 | 示例 |
|------|------|------|
| `{nickname}` | 用户昵称 | `你好{nickname}！` |
| `{url:链接}` | 获取链接内容（支持图片和文本） | `今日壁纸：{url:https://example.com/img.jpg}` |
| `{page:链接}` | 把网页渲染为图片发送 | `网页截图：{page:https://example.com}` |
| `{rand}` | 0 ~ 100 的随机数 | `{rand}` |
| `{rand:数值}` | 0 ~ 该数值的随机数 | `{rand:10}` |
| `{rand:最小数值,最大数值}` | 指定范围内的随机数 | `{rand:1,100}` |
| `{rand:文本1,文本2,...}` | 随机选择一个文本 | `{rand:你好,再见}` |
| `{date}` | 当前日期 | `{date}` → `2026年09月15日` |
| `{date:格式}` | 指定格式的当前日期 | `{date:YYYY-M-d ddd}` → `2026-9-15 周二` |
| `{time}` | 当前时间 | `{time}` → `14:30:05` |
| `{time:格式}` | 指定格式的当前时间 | `{time:HH时mm分}` → `14时30分` |
| `{face}` | 随机发送一张表情图片 | `这是一个表情：{face}` |

### URL 变量说明

`{url:链接}` 会智能检测内容类型：

- **图片链接**：自动发送图片（支持 PNG/JPG/GIF/WebP）
- **文本内容**：自动插入到回复中
- **混合使用**：文本和图片可同时发送

### 网页变量说明

`{page:链接}` 会把网页渲染为图片发送，适合普通网页；`{url:链接}` 则抓取链接的文本内容，适合请求 API 获取数据。

- 渲染依赖Playwright：需要提前安装好 `playwright` 与 Chromium
- 可选参数按顺序为渲染时间（毫秒）、宽度、高度，缺省为 `1000`、`1280`、`720`：`{page:链接}`、`{page:链接, 渲染时间}`、`{page:链接, 渲染时间, 宽度}`、`{page:链接, 渲染时间, 宽度, 高度}`
- 参数项必须整个都是数字，否则会当作链接的一部分；链接本身含逗号且尾部是数字时，用单/双引号包裹链接，如 `{page:'https://example.com/1,2,3', 1500}`
- 异步渲染的页面用默认 1000 毫秒可能截不到内容，可把渲染时间调大

### 随机变量说明

`{rand}` 会根据参数结构自动切换为随机数或随机文本：

- **随机数**：1 ~ 2 个数值参数时替换为范围内的随机数，单个数值参数视为 `0` ~ 该数值，最小值与最大值顺序颠倒时会自动交换
- **小数位数**：随机数的小数位数由参数中数值的小数位数决定，取最长的那个，如 `{rand:1,20}` 输出整数、`{rand:1,20.0}` 输出 1 位小数、`{rand:1.50,2.500}` 输出 3 位小数
- **随机文本**：参数超过 2 个，或参数中出现非数值时，随机选择其中一个文本
- **强制文本**：用单/双引号包裹数值即可按文本处理，如 `{rand:'1', '100'}` 只会随机回复 `1` 或 `100`
- **引号保护**：引号内的逗号不会被拆分，如 `{rand:'早安,主人',晚安}` 会随机回复 `早安,主人` 或 `晚安`
- **原样输出**：用反引号包裹的内容会原样输出，不剥离引号、也不解析其中的变量，如 `` {rand:`'100'%`,`json结果是{"object":"rabbit"}`} ``
- **嵌套**：参数内可以再写其他变量，随机替换会从外到内逐层解析，如 `{rand:{nickname}掷出了{rand:1,6}点！}`
- 参数两侧的空格会被忽略，数值为 `0` 的单个参数按文本处理

### 日期与时间变量说明

`{date}`、`{time}` 以系统日期时间为准：

- `{date}` 输出当前日期，默认格式为 `YYYY年MM月dd日`
- `{time}` 输出当前时间，默认格式为 `HH:mm:ss`
- 格式符号与 Windows 日期时间格式一致：

| 符号 | 说明 | 示例 |
|------|------|------|
| `y` / `yy` | 两位年份 | `26` |
| `yyyy` | 四位年份 | `2026` |
| `M` / `MM` | 月份 | `9` / `09` |
| `MMM` / `MMMM` | 月份名称 | `9月` / `九月` |
| `d` / `dd` | 日期 | `5` / `05` |
| `ddd` / `dddd` | 星期 | `周二` / `星期二` |
| `H` / `HH` | 24 小时制小时 | `14` |
| `h` / `hh` | 12 小时制小时 | `2` / `02` |
| `m` / `mm` | 分钟 | `30` |
| `s` / `ss` | 秒 | `5` / `05` |
| `t` / `tt` | 上午 / 下午 | `下午` |

- 格式中的其他字符会原样输出，如 `{date:今天是YYYY年M月d日}` → `今天是2026年9月15日`

### 表情变量说明

`{face}` 会从 `resource/plugins/user/face` 目录随机读取一张图片发送，可自行向该目录添加表情图片。

### 使用示例

**基础问答：**
- 关键词：`你好`
- 回复：`你好{nickname}，很高兴见到你！`

**发送图片：**
- 关键词：`壁纸`
- 回复：`今日壁纸：{url:https://example.com/wallpaper.jpg}`

**获取网页内容：**
- 关键词：`天气`
- 回复：`今天的天气是：{url:https://wttr.in/Beijing?format=3}`

**随机数值：**
- 关键词：`骰子`
- 回复：`你掷出了 {rand:1,6} 点`

**随机文本：**
- 关键词：`选择`
- 回复：`那就 {rand:吃火锅,吃烧烤,吃日料} 吧`

**当前日期与时间：**
- 关键词：`报时`
- 回复：`{nickname}，现在是 {date:YYYY年M月d日 dddd} {time:HH时mm分ss秒}`

**网页截图：**
- 关键词：`截图`
- 回复：`{nickname}，你要的截图：{page:https://example.com, 1500}`

**随机表情：**
- 关键词：`表情`
- 回复：`{nickname} 收到了一个表情：{face}`

**组合使用：**
- 关键词：`帮助`
- 回复：`{nickname}，这是帮助信息：{url:https://example.com/help}`
