- 使用前请先在「大语言模型调用库」中配置模型提供商与 API Key，推荐使用「OpenAI SDK 兼容」接入任意现代模型服务。
- 默认对所有群聊开放；如需限制成本，可在全局配置把「生效范围」切为「仅白名单」，并用「频道信息」指令获取群 ID 填入白名单。
- 对机器人说：`@机器人 你好`，或私聊任意内容，即可开始与 AI 聊天。
- 群聊中包含昵称触发词（如「阿米娅」「兔兔」）的消息也会获得回复。
- AI 回复后 2 分钟内，同一位用户可以继续对话，无需再次 AT。
- 群里的普通闲聊默认不会被打断；只有当没有任何功能命中时，AI 才会兜底回应。
- 若某群不希望 AI 参与闲聊，可在控制台为该频道开启「仅AT响应」，或直接关闭该插件功能。
