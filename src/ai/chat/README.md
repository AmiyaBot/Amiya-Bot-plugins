# AI 对话

基于大语言模型（LLM）的智能聊天插件。它会默默收集群聊上下文，**只在没有其他插件功能响应时**作为兜底出场，与大家聊天。

## 它是如何做到"不抢话"的

机器人的每条消息都会先经过所有插件功能的匹配，权重最高的响应获胜：

| 消息类型 | 谁来响应 |
| --- | --- |
| 指令与功能（查干员、签到、自定义回复等） | 对应插件功能（权重均 ≥ 0，永远优先） |
| AT 机器人 | 有功能命中时由该功能响应；否则由 AI 结合上下文回复 |
| 包含昵称触发词（默认：阿米娅 / 兔兔 / Amiya） | AI 结合上下文回复 |
| AI 回复后短时间内同一位用户继续发言 | AI 延续这段对话 |
| 其余普通闲聊 | 默认**不回复**，只默默记入上下文；开启「主动插话」后以极低概率参与 |

因此安装本插件不会影响任何现有功能，也不会在群聊里刷屏。

## 使用前提

本插件依赖 [大语言模型调用库]（amiyabot-blm-library），请先在该插件的全局配置中：

1. 启用一个模型提供商。推荐使用 **OpenAI SDK 兼容**，任何兼容 OpenAI 接口的服务均可（DeepSeek、智谱 GLM、通义千问、Kimi、OpenRouter、硅基流动等），填入模型名称、base_url 和 API Key 即可。
2. 设置「默认模型」，或在本插件的「对话模型」中指定模型名。

## 生效范围与成本控制

AI 对话默认**全局开放**（所有群聊 + 私聊）。如果机器人加入了较多群、希望控制 API 成本，可以在全局配置中把「生效范围」切换为「仅白名单」，并在「群聊白名单」中填入允许使用 AI 对话的群聊 ID（在对应群里向机器人发送 `频道信息` 即可获得该群 ID）。白名单模式下私聊不受影响。

此外还可以按群细化：频道配置中的「启用」可单独关闭某个群的 AI 对话，「仅AT响应」可让该群只在被 AT 时回应。

## 群聊中的行为

- **接收全部消息模式**：机器人后台会记录最近的聊天内容（默认 20 条、30 分钟内）作为上下文，但不会回复普通闲聊。
- **AT 机器人**：一定回应，且回复会参考最近的聊天上下文。
- **连续对话**：AI 回复后 120 秒内，同一位用户继续发言会被视为延续对话，无需反复 AT。
- **主动插话**（默认关闭）：开启后 AI 会以很低的概率（默认 3%）和冷却时间（默认 5 分钟）自然地加入闲聊话题。

以上参数均可在控制台按群（频道）独立配置，例如给某个群开启「仅AT响应」。

## 剧情与世界观问答

已安装「明日方舟数据解析」插件并完成资源初始化后，AI 对话会自动检索游戏剧情语料（全部干员/NPC 档案 + 主线与活动剧情文本），把相关资料注入提示词后再回答。可以自然地问：

- 「介绍一下卡兹戴尔」
- 「赫德雷和伊内斯的关系」
- 「生于黑夜的剧情讲了什么」

回答会基于检索到的档案与剧情原文，资料里没有的内容会明确表示不确定而不是编造。干员数值、材料、公招等查询仍由对应的明日方舟插件负责，AI 只在无插件命中时兜底回答。

## 私聊

私聊消息没有其他功能命中时，AI 会直接回应。

## 指令

本插件没有专属指令。使用 `功能` / `帮助` 查看与管理所有功能。
